# React Todo App

A simple Todo application built with React and Vite.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks
- LocalStorage persistence

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- LocalStorage
- Lucide React
